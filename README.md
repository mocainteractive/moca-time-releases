# Moca Time

Il time tracker di Moca per Mac, collegato a **Project**. Questo repository contiene solo le versioni pubblicate dell'app; il codice sorgente è privato.

## Installazione

Apri **Terminale** (⌘ + Spazio, scrivi "Terminale", Invio), incolla questa riga e premi Invio:

```bash
curl -fsSL https://github.com/mocainteractive/moca-time-releases/releases/latest/download/install.sh | bash
```

Lo script scarica la versione giusta per il tuo Mac (chip Apple o Intel), la installa in Applicazioni e la apre.

In alternativa puoi scaricare il DMG dalla [pagina delle release](https://github.com/mocainteractive/moca-time-releases/releases/latest): `-arm64` per i Mac con chip Apple, `-x64` per i Mac Intel. Al primo avvio servirà *Impostazioni di Sistema › Privacy e sicurezza › Apri comunque*.

## Aggiornamenti

Sono automatici: Moca Time scarica le nuove versioni in background e le installa al riavvio successivo. Per aggiornare subito: *Impostazioni › Aggiornamenti › Controlla aggiornamenti*.
